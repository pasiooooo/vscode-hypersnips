# 多行单元格处理说明

状态：共享列位置的多行格式化方案已撤回，当前性能分支不启用该布局。

外层表格不会平移多行单元格、统一其内部缩进，或把手写分隔符移动到共享的源码列位置。源码换行、相对缩进、内容顺序和内部 Tab 保持原样；普通单行数据继续按已有规则对齐。

保留撤回前已有的逻辑行识别与智能按键：

- 单元格由外层 `&` 分开，逻辑行由外层 `\\` 或 `\tabularnewline` 结束；公式、括号组、注释和嵌套环境中的分隔符不计入外层结构。
- Tab 可以跳到下一源码行上的有效 `&`；单元格中的独立公式不会被外层表格插入 `&` 或 `\\`。
- 多行逻辑行内的 Enter 只增加源码换行，未结束行不抢填空列。
- 已结束行继续参与列数同步；删除尾部空列时，以当前行列数和所有行最后一个有内容的列确定下限，并同步受支持的列声明。
- 嵌套矩阵等环境仍使用其自身的智能按键与对齐规则。

`\lstinline`、`\mintinline`、`\Verb` 等代码内容的保护继续保留。未知自定义列格式、动态列数及尚未闭合的结构不作猜测；列声明中的注释不会因缩列被删除。

这次撤回不移除 `dcases`、`drcases`、星号矩阵等环境变种支持，也不改变字体识别、片段引擎或自动对齐开关。
